# Module Boundaries

auth: identity and sessions
tenant: tenants and memberships
user: user profile
business: business and locations
campaign: campaign lifecycle
audience: audience definitions
geo: geographic targets
creative: creative drafts/assets metadata
platform: provider connections and adapters
analytics: metrics
lead: leads
ai: AI providers/recommendations/usage
billing: plans/subscriptions/limits
notification: notification abstraction
admin: platform administration
common: shared technical concerns
