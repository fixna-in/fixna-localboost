# Project Overview

Brand: Fixna
First product: Fixna LocalBoost
Domain: fixna.in

LocalBoost helps local businesses define promotions, geography, audience and budget,
receive AI recommendations, generate creatives, approve campaigns, execute through
advertising platforms and monitor leads/metrics.

Initial market: India, starting with Noida/Greater Noida/Delhi NCR.

Initial categories: restaurants, cafes, salons, gyms, clinics, coaching institutes,
retailers, home services, automotive services.

LocalBoost is an orchestration/intelligence layer, not a replacement for Google Ads,
Meta Ads or WhatsApp.
