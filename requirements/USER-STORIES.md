# User Stories

US-001 As a business owner, I can register.
US-002 As a user, I can create a tenant.
US-003 As a tenant owner, I can invite/manage users.
US-004 As a tenant user, I can create a business.
US-005 As a business user, I can add locations.
US-006 As a business owner, I can create a campaign.
US-007 As a campaign user, I can select a geographic area.
US-008 As a campaign user, I can define an audience.
US-009 As a campaign user, I can define budget and duration.
US-010 As a campaign user, I can request AI recommendations.
US-011 As a campaign user, I can review creatives.
US-012 As a campaign owner, I can approve a campaign.
US-013 As a campaign owner, I can launch a mock campaign.
US-014 As a campaign user, I can view metrics.
US-015 As a business user, I can manage leads.
US-016 As an admin, I can inspect tenants.
US-017 As an admin, I can inspect audit events.
US-018 As a tenant, I can see AI usage against limits.
